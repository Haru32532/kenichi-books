けんちゃんの本棚 v11

主な変更
- 分析: 現在累計・今月回数・暦日平均・設定した1日目標・達成年齢までの必要ペース
- 分析: 月を選択して、その月の読み聞かせランキングを表示
- 設定: 達成年齢、1日目標、平日のみ、祝日除外
- 店頭チェック: ISBN一致なしでも所有候補を表示
- 店頭チェック: 本棚検索から既存本へISBN/不足書誌を統合して編集
- ISBN書誌: openBD詳細書誌から著者・出版社も補完
- 図書館A/B/C・読み聞かせカレンダー等v10の正常機能を維持

注意
- 日本の祝日除外は3歳到達までに必要な2026-2028年の祝日を内蔵。
- 図書館のリアルタイム所蔵確認にはカーリルAPIキーとsystemidが必要。
