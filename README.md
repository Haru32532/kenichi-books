# けんいちくんの本棚 v0.5 iPhone/PWA版

初期データ: 314タイトル。

## 実装済み
- 所有本検索・編集
- タイトル/作者/出版社の五十音順、中古相場、レア度、優先度ソート
- JAN/ISBN(EAN-13)カメラスキャン + openBD検索
- 所有済み判定
- 目標CSV/JSONとの差分による不足本リスト
- ブラウザ印刷からPDF保存
- ChatGPT連携用サーバーAPI
- Copilot Studio REST連携用 `/api/library` とOpenAPI雛形
- Supabaseによる同一ログインの複数端末同期
- ミーテPDFアップロード入口（誤集計防止のためv0.1では自動回数加算なし）

## 起動
Node.js 20以上で `npm start` → http://localhost:8787

## ChatGPT
APIキーをブラウザに置かず、サーバー環境変数 `OPENAI_API_KEY` に設定してください。
例: `OPENAI_API_KEY=... npm start`

## 家族共有
Supabaseでプロジェクトを作成し `supabase.sql` を実行。
アプリの共有画面にProject URL / anon key / メール / パスワードを入力し、各端末で同じログインを使用します。

## 中古相場・レア度
入力・表示・ソートは実装済み。販売サイトからの自動取得は各サイトのAPI/利用規約確認が必要なため、現版では自動取得しません。

## ミーテ
実際のミーテPDF様式に合わせた正確な回数抽出ルールを次段階で実装する前提です。現在はアップロードUIまで実装しています。


## v0.2 追加
- BOOKOFFモードに比較価格欄を追加:

### 価格取得について
v0.2は各市場の検索画面を開き、条件に合う商品の価格をアプリに記録する方式です。
外部サイトの検索結果を無断スクレイピングして自動取得する機能は入れていません。
公式APIや利用許諾を確保できた取得元は、後から自動化できます。


## v0.3 追加
- BOOKOFF店頭価格を入力して比較検索
- 「検索上限金額」を任意入力
- BOOKOFF / メルカリ / ラクマ / VALUE BOOKS の登録済み価格を横並び比較
- 上限金額以下なら「購入候補」、超過なら「見送り候補」
- 登録済み比較価格の中でBOOKOFFが最安なら表示
- 店頭でISBNスキャン後、そのまま金額を入れて再判定可能

注意: 外部マーケット側の検索結果を価格上限で自動フィルタする機能は、各サイトの公開仕様/APIに依存します。v0.3の「上限金額」はアプリ内の購入判定条件です。
