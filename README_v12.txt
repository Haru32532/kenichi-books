けんちゃんの本棚 v12

v11の全機能に加えて、本のコード読み取りを拡張しました。
- ISBNバーコード（978/979）を読み取り
- 書籍JAN第2段（192）からCコード・本体価格を取得
- 印刷されたISBN-10/ISBN-13をカメラ文字認識
- ISBN-10をISBN-13へ変換しチェックデジット検証
- 印刷された Cxxxx と ¥xxxE / ￥xxxE を同時認識
- 店頭チェック／新規登録／所有本編集で共通利用
- 新規登録にもCコード・本体価格欄を追加

文字認識は端末上のカメラ画像をTesseract.jsで処理します。初回はライブラリ読込のため数秒かかる場合があります。
